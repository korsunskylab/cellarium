# figs

Standalone diagnostic figures, mostly produced by preprocessing scripts.

| File | Produced by | What it shows |
|---|---|---|
| `_roi_candidates.json` | `scripts/preview_roi_candidates.py` | Candidate ROI bounding boxes with summary stats |
| `_roi_candidates_overview.png` | `scripts/preview_roi_candidates.py` | Slide-level view with candidate ROIs marked |
| `_roi_candidates_minimaps.png` | `scripts/preview_roi_candidates.py` | Mini-views of each candidate ROI side-by-side |
| `_roi_candidates_morphology.png` | `scripts/preview_roi_candidates.py` | Morphology channel previews per candidate |

Underscore prefix indicates auto-generated / regeneratable.
