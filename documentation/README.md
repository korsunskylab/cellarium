# documentation/

Knowledge-output artifacts that help a reader catch up on the project without
running any code: methods descriptions, design rationales, distilled
experimental findings.

What lives here:
- `methods_boundary_prior.md` / `.docx` — methods text for the V0
  boundary-prior pipeline (`pipelines/V0/`).
- Single-page write-ups distilled from sandbox experiments (e.g.
  `diameter_quality.md`, `merge_vs_scale.md`, `onion_ring_stitching.md`,
  `github_issue_draft.md`).

What does NOT live here:
- Code (see `pipelines/V0/`, `analyses/scripts/`, `sandbox/scripts/`).
- Cached data (see `data/`).
- Large rendered figure dumps — sandbox runs produce their own.
